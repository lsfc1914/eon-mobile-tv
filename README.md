# EON Mobile TV Player (Android / Kotlin / Jetpack Compose / Media3)

Пълен проект за мобилен TV плейър с поддръжка на:
- M3U / M3U8 плейлисти (URL и локални файлове) с категории (`group-title`), логотипи (`tvg-logo`) и **архив / catch-up** (`catchup-source`, `catchup-days`, `catchup`)
- HLS, DASH и MP4 потоци чрез Media3 ExoPlayer
- Външен XMLTV и `.xml.gz` EPG по `tvg-id` + автоматично фоново опресняване на всеки 6 часа чрез WorkManager
- Любими канали (`DataStore`), бързо превключване, пълен екран, жестове за яркост и звук, авто-презареждане при прекъсване

## Функции
- **Архив (catch-up)** — гледайте излъчени предавания от „ТВ Програма“ за канали с `catchup-source`
- **ТВ Програма (Guide)** — цялодневна програма по канали: НА ЖИВО / ИЗЛЪЧЕНО / ПРЕДСТОИ, прогрес и възпроизвеждане на записи
- **Избор по номер** — цифрова клавиатура за директно превключване към канал
- **Аудио и субтитри** — избор между наличните аудио потоци и субтитри на канала
- **Картина в картината (PiP)** — гледайте телевизия и при напускане на приложението
- **Таймер за заспиване** — 15/30/45/60/90/120 минути с обратно броене
- **Жестове** — ляво плъзгане = яркост, дясно = звук, двоен докос вляво/вдясно = −10/+10 сек, в средата = пълен екран

## Билдване в GitHub Actions (0 RAM на твоя компютър)
1. Създай ново празно репозитори в GitHub.
2. Качи всички файлове (включително скритата папка `.github/workflows/build-apk.yml`).
3. Отвори таба **Actions** в GitHub -> избери **Build EON TV Debug APK** -> след приключване свали артефакта `eon-tv-debug-apk` (`app-debug.apk`).
